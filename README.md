# Faro Scoop Bucket

Official Scoop bucket for **Faro Desktop**.

## How to Install

1. Make sure [Scoop](https://scoop.sh) is installed on your Windows machine:

   ```powershell
   Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
   irm get.scoop.sh | iex
   ```

2. Add this bucket to Scoop:

   ```powershell
   scoop bucket add faro https://github.com/MEvesalTR/scoop-bucket
   ```

3. Install Faro:
   ```powershell
   scoop install faro
   ```

## How to Update

To update Faro to the latest version:

```powershell
scoop update faro
```

## How to Uninstall

```powershell
scoop uninstall faro
```
